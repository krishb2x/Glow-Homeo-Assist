# Product Roadmap

## Q3 2026: WhatsApp Expansion
- **Interactive Check-ins:** Expanding the Care Plan library with dynamic WhatsApp forms for symptom tracking.
- **AI-Powered Inbox:** Using LLMs to draft suggested replies for the Clinical Channel inbox.

## Q4 2026: Clinical Deepening
- **Repertorisation Integration:** Embedded Materia Medica search directly inside the 9-step consultation workspace.
- **Treatment Outcome Analytics:** Aggregating clinical outcomes across demographics for clinic-wide insights.

## Q1 2027: Enterprise Scale
- **Franchise Rollout Support:** Hierarchical RLS policies to allow Super-Clinics to view aggregate data across multiple child locations.
- **Advanced Telemetry:** Deep Datadog integration for proactive issue alerting.
